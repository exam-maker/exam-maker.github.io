# 영어 내신 기출 분석 & 변형문제 생성 웹앱

영어 내신 시험지(기출)를 AI로 분석해 출제 설계도를 만들고, 같은 유형과 난이도의 변형문제를 생성해 문제지·정답표·해설을 인쇄하거나 PDF로 저장하는 웹앱입니다. 설치 없이 브라우저에서 바로 사용할 수 있습니다.

**접속 주소:** https://exam-maker.github.io/

## 주요 기능

**설계도 만들기:** 기출 시험지 파일을 올리면 AI가 문항별 유형, 난이도, 배점, 출제 경향을 분석해 설계도 카드로 정리합니다. 분석 결과는 직접 수정할 수 있습니다.

**시험 범위(지문) 관리:** 변형문제의 바탕이 되는 지문을 추가, 수정, 삭제할 수 있으며, `---` 줄로 구분하면 여러 지문을 한 번에 입력할 수 있습니다.

**변형문제 생성:** 지문과 설계도를 선택하면 AI가 설계도의 유형과 난이도에 맞춰 새 문제를 만듭니다. 생성된 문제는 개별적으로 검산할 수 있고, 같은 난이도·쉽게·어렵게 옵션으로 다시 만들 수 있습니다. 기출 원문은 AI에 보내지 않고 설계도 항목만 전달하므로 원문이 외부로 전송되지 않습니다.

**출력:** 저장된 세트를 골라 문제지, 정답표, 해설을 포함 여부를 선택해 인쇄하거나 PDF로 저장합니다. A4 기준으로 출력되며, 로고 위치와 크기는 설정 탭에서 바꿀 수 있습니다.

**설정:** 학원명과 로고(PNG, JPG, 1MB 이하)를 등록하고, AI 제공자와 API 키, 단계별 모델을 고를 수 있습니다. 백업 내보내기와 불러오기도 이곳에서 합니다.

## 사용 전 준비

이 앱은 본인의 Gemini API 키를 사용합니다. 키는 Google AI Studio(https://aistudio.google.com/apikey)에서 무료로 발급받을 수 있으며, 보통 `AIza`로 시작합니다. 발급받은 키는 설정 탭의 API 키 칸에 입력한 뒤 **연결 테스트**를 눌러 확인하세요. 무료 키는 일일 사용 한도가 있으므로, 한도를 넘으면 안내 문구가 표시됩니다.

처음 사용할 때는 동의 화면이 나오며, 4개 항목에 모두 동의해야 기능을 사용할 수 있습니다.

## 데이터 저장 방식

작성한 설계도, 지문, 세트는 **사용 중인 브라우저 안에만** 저장됩니다. 서버에 보관되지 않으므로 다른 브라우저, 시크릿 창, 다른 컴퓨터에서는 보이지 않습니다. 브라우저의 사이트 데이터를 삭제하면 자료도 함께 사라지니, 중요한 자료는 설정 탭에서 **백업 내보내기**로 정기적으로 저장해 두세요.

백업 파일에는 API 키가 포함되지 않습니다. 다른 주소나 기기에서 이어서 쓰려면 백업 파일을 내보낸 뒤 해당 환경의 설정 탭에서 **백업 불러오기**를 누르고, API 키는 다시 입력해야 합니다.

## 권장 환경

Chrome 또는 Edge 최신 버전에서 사용하는 것을 권장합니다. 인쇄나 PDF 저장은 Chrome 인쇄 창에서 배경 그래픽 옵션을 켜면 더 정확하게 출력됩니다.

## 문의 및 의견

사용 중 불편한 점이나 제안은 설정 탭 맨 아래의 **의견 보내기** 버튼으로 전달해 주세요.

## 주의 사항

기출 문제와 시험지는 저작물이므로, 저작권을 가진 자료를 공개 목적으로 배포하거나 외부에 공유하지 않도록 유의해 주세요. AI가 생성한 문제와 해설은 반드시 교사가 검토한 뒤 사용하시기 바랍니다.
